# מיפוי מבחן אוטומטי

כלי למורים למתמטיקה: מעלים מבחן (Word / PDF / טקסט), המערכת מזהה שאלות, סעיפים וניקוד, מציעה רמת חשיבה לכל סעיף (ברירת מחדל: ידע וזיהוי / אלגוריתמי / חשיבה תהליכית / פתוח, יעד 20/30/30/20), משלבת רשימת תלמידים (או 40 שורות ריקות) ומייצאת מיפוי מוכן ל-Excel / CSV.

קובץ אחד – `index.html` – רץ כולו בדפדפן, בלי שרת. אפשר לפתוח ישירות או להפעיל GitHub Pages על הענף.

## מה יש בקובץ האקסל
- גיליון "מיפוי": שאלה / סעיף / רמת חשיבה / תיאור / ניקוד מרבי, תאי מילוי צהובים, נוסחאות לסה״כ ולציון, אימות ניקוד (0 עד המרבי), ממוצע כיתה ואחוז הצלחה לכל סעיף (אדום מתחת ל-55%).
- גיליון "סיכום": לפי רמת חשיבה (ולפי נושא אם הופעל), התפלגות ציונים, ממוצע וחציון.
